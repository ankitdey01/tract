# Tract

Turning git commits into ready-to-post drafts in the author's own voice, always reviewed before publishing.

## Language

**Significance**:
Whether a change is worth posting about, decided solely by the Jev gate.
_Avoid_: importance, relevance, interest

**Draft**:
A generated post candidate for one platform from one commit, requiring human review before publish.
_Avoid_: post, content, output

**Voice Profile**:
The author's reusable writing voice, pairing the default voice with one platform-specific voice.
_Avoid_: tone settings, style config, persona

**Voice Sample**:
One pasted excerpt appended to the voice profile.
_Avoid_: example, training data, seed

**Commit Target**:
The committed commit generation and publish operate on, defaulting to the last commit.
_Avoid_: diff input, revision, working copy

**Publish**:
The browser-based handoff of an approved draft — true prefill where the platform supports it, copy-plus-open otherwise.
_Avoid_: posting, auto-publish, sharing
